MAS 创作工具箱 — 主题工坊 + 桌宠工具

解压整个文件夹后，双击 MAS主题工坊.exe 即可运行。
无需安装 AUTO-MAS、Node.js 或 Python。本地编辑与导出无需联网；AI 生图需联网。
请保留 EXE 同目录的 resources、locales 等文件，不要只复制 EXE。

制作主题
新建主题使用 MAS 默认蓝色（#1677ff），其他颜色由与 MAS 相同的 Ant Design Vue 算法生成。
未修改的颜色不会写入 theme.json；选择配色或手动修改的字段才会成为覆盖值。
「恢复 MAS 默认配色」只恢复颜色，不删除已导入的素材。
1. 在「主题信息」填写名称、主题标识和简介。
   标识仅支持小写英文、数字、短横线与下划线，不能使用 Windows 保留名。
   在 AUTO-MAS 中，相同标识表示同一个主题，导入时可能询问覆盖。
2. 在「配色与背景」选择模式、配色或自定义颜色，导入背景图片。
   可以调整背景不透明度、卡片不透明度、填充方式、位置和圆角。
   切换浅色/深色模式会重置基础底色、文字色及边框色，保留主题色。
3. 在「图片素材」按需导入主题封面、菜单图标、桌宠形象和鼠标光标。
   素材支持拖放到对应区域。各项均可不设置。
   菜单支持默认图标和逐菜单图标；未配置的菜单使用默认图标。
   只显示正式界面的菜单；旧包中已有的开发者图标保留并继续导出。
   桌宠支持单图和已有 mascot.json 桌宠 ZIP；导入 ZIP 会保留全部动画和菜单声明。
   动画预览播放待机动作，全部动作均会被导出。替换为单图会移除原动画。
   鼠标光标只支持 PNG，宽高各为 1–64 像素，热点必须在图内。
4. 在「检查与导出」检查主题，或直接点击右上角「导出主题包」。
   导出时使用 AUTO-MAS 的主题规则校验，生成 theme.json + assets 的标准 ZIP。
5. 在 AUTO-MAS 主题商店中点击「导入外观包」，选择 ZIP 后应用主题。

AI 生图
在左侧「AI 生图」中填写 API 地址、API Key 和模型名。
默认地址：https://api.openai.com/v1
默认模型名：gpt-image-2；可改为你所用服务商提供的生图模型。
兼容 POST /images/generations，支持基础地址或完整接口地址。
可选最多 4 张参考图（PNG/JPEG/WebP，单张 8 MB、总计 16 MB），并在提示词中说明参考人物、配色或风格。
添加参考图后自动使用 /images/edits 文件上传接口，服务商及模型需支持参考图生成。
参考图可以预览和移除；成功生成时随素材归档在本机，不加入主题包。生成时随提示词上传到所填服务商。
点击「根据参考图生成提示词」，填写支持图片输入的看图模型，按当前用途和风格分析参考图。
默认复用生图地址与密钥，也可勾选独立看图服务，填写另一组地址、模型和密钥；接口需兼容 /chat/completions。
结果先显示为可编辑的候选，点击「使用此提示词」才替换当前内容；失败和取消不覆盖原文。
看图时会上传参考图与用途要求，由所选服务计费；看图密钥仅本次运行使用。
API 地址通常以 /v1 结尾；支持 HTTPS，localhost 本机服务可用 HTTP。
这不是 ChatGPT 网页登录，不会使用 Codex 的订阅额度；由所填 API 服务商计费。

1. 选择用途：主题背景、主题封面、菜单图标、静态桌宠、鼠标光标。
2. 修改「灵感与风格」后点击「套用内置提示词」，也可直接编辑整段提示词。
3. 调整尺寸后生成；单张模式只请求 1 张图片。
   菜单图标可选单张用途，或勾选整套生成（10 个正式菜单 + 1 个默认图标）。
   每个图标都使用自己的用途与主体提示词，可逐项修改；共用画风、配色和原参考图。
   整套会顺序发起 11 个请求、分别计费。失败或取消后保留已完成项，可继续剩余项或单独重生成。
4. 在右侧预览结果，再点击「应用为…」或「保存图片」。
   背景与封面保留原图；图标应用时缩小至128px以内，光标缩小至64px以内。
   生成静态桌宠后，应用它会替换原来的动画桌宠。
   整套图标先预览，再勾选要使用的项目统一应用。

本地素材库
每张成功生成的原图会自动保存，同时记录用途、提示词、风格、模型、生成时间及当时的参考图。
在 AI 生图中点击「打开本地素材库」，可预览、分页、选用原图或复用提示词。
「选用图片」先恢复右侧原图预览，再确认应用；「复用提示词」不发起收费请求。
「复用提示词」会按原顺序恢复当时的参考图，并替换当前选择；当时无参考图的新记录恢复为 0 张。
重启后点击复用即可带上参考图，API Key 仍需重新填写。服务地址和模型请自行确认。
v1.3 及更早记录没有保存输入参考图，会提示检查当前选择；需要自行添加，无法自动找回旧文件。
批量图标同样逐张保存原图；应用到主题时的缩小处理不影响素材库中的原图。
新建主题或退出不会清空素材库。相同图片与生成说明会去重，不自动删除已存图片。
图片存放在 data/generated-images；配套 JSON 记录说明，thumb.png 是预览小图。
可点击「打开素材文件夹」查看实际位置。目录不可写时使用系统应用数据目录。
升级解压到新文件夹或换电脑时，请备份并迁移整个 data 文件夹。
原图保存失败会提示重试；批量生成会暂停，重试保存不会重新调用生图接口。
旧草稿仍保留的最后结果会补存；过去已经被覆盖且未另存的图片无法恢复。
输入参考图在 generated-images/references 内按内容去重，保留原始字节、文件名与顺序。
API Key 不存入素材库；主题 ZIP 仅包含应用到主题的图片。
更多图文步骤见同目录 guide.md，配图在 docs/images 内。

默认不传额外质量和返回格式参数，以兼容更多服务。
高级选项可选质量、b64_json / url 返回格式、透明背景。
部分接口不支持这些参数，遇到参数错误可恢复默认。
透明背景选项需模型支持，提示词写透明并不能保证生成图片确实透明。
支持 data[0].b64_json 和 data[0].url，不支持聊天补全接口或异步任务轮询式生图接口。
最长等待 5 分钟，可取消；取消本地等待不能保证服务商停止任务或退还已消耗额度。

API Key 只在本次运行内使用，不写入草稿、主题 ZIP 或日志。
API 地址、模型、提示词及最后一次生成结果（单张或整套图标）会随草稿保存在本机。
生成时向所填地址发送提示词、授权密钥和明确选择的参考图，不自动上传主题中的其他素材。
若接口以图片链接返回，下载图片不会附带 API Key。
内置提示词与请求代码可在 source.zip 中 src/ai.ts、src/image-api.cts 查看。
官方接口参考：https://developers.openai.com/api/reference/resources/images/methods/generate

继续编辑
点击「打开主题 ZIP」可以重新编辑已导出的主题，含动画资源。
打开主题和新建主题都会替换当前草稿，请先导出需要保留的内容。
当前草稿自动保存，并在退出前保存最后一次修改，重启后恢复。
草稿位于工具同目录的 data 文件夹。目录不可写时，使用系统应用数据目录。
转移电脑、备份或分享前请导出 ZIP，不要仅依赖草稿。
示例主题-林间来信.zip 可以直接打开体验；示例图片为本工具绘制的几何山林。
示例桌宠素材来自先前制作的奶油猫演示包，只作功能演示。

格式限制
- 单张图片最大 8 MB，宽高均不超过 8192 像素。
- 主题 ZIP 最大 16 MB，解压后总量最大 32 MB，最多 31 个图片文件。
- 图片只支持 PNG、JPEG、WebP；不支持 SVG、GIF、视频或代码扩展。
- 桌宠动画须符合 AUTO-MAS 图集规则，通过导入桌宠 ZIP 添加。
- 图片按原始质量保存，不会自动裁剪或压缩。
- 右侧复用 MAS 的 AppLayout、主页快速开始、常用入口组件及主题算法。
- 预览铺满右侧可用区域，宽高随窗口、最大化、全屏和还原同步调整，MAS 内容按实际预览尺寸布局。
- 主页业务数据仅作预览；组件预览页面展示表格、表单等组件，不会执行任何任务。
- 桌宠按 MAS 的独立桌面悬浮窗口方式单独预览，不覆盖在主界面上。
- 工具界面使用浅色，主题预览支持浅色和深色。

兼容性与许可
主题格式对应 AUTO-MAS upstream/dev 的快照，具体提交见 resources/app.asar 内 compat/SOURCE.txt。
导出已经实际通过该版本的 AUTO-MAS 导入与列表读取校验。
未对安装在你电脑上的 AUTO-MAS 进行改动。旧版本可能不支持较新的桌宠动画格式。
这是未做代码签名的本地工具。
本工具包含 AUTO-MAS 的 AGPL-3.0 校验模块，完整源码及原始 TypeScript 在 source.zip。
Electron 和 adm-zip 的许可证随包提供。

桌宠工具
点击顶部「桌宠工具」打开同一程序内置的桌宠预览器，无需另一个安装包。
在「图片素材」点击「在桌宠工具中预览」可直接发送当前主题的桌宠，无需先导出文件。
支持 ZIP、PNG、JPEG、WebP，支持待机、工作、成功、失败、拖拽、视线和静态形象。
支持播放/暂停、逐帧、图集检查、列数/帧数检查、1–120 FPS、尺寸、透明度、浅深背景。
单图参数只影响预览，不会改写原始图集。
在主题工坊「图片素材」点击「导出独立桌宠包」可生成标准 mascot.json ZIP，保留全部动作资源。
独立桌宠导出只包含桌宠素材，不包含主题背景、菜单图标等无关图片。
