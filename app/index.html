开始制作你的主题
1. 填写名称和唯一标识，选择浅色或深色配色。
2. 在「配色与背景」导入背景并调整透明度。
3. 可在「AI 生图」填写兼容接口、模型和 API Key，用内置提示词生成素材，再应用到主题。
4. 按需添加封面、菜单图标、桌宠和鼠标光标。
5. 导出 ZIP，在 AUTO-MAS 的主题商店中导入并应用。
草稿自动保存在工具旁的 data 文件夹中（目录不可写时使用系统应用数据目录）。打开主题 ZIP 可继续修改；转移电脑前请先导出 ZIP。
图片最大 8 MB、宽高不超过 8192 像素；最终 ZIP 最大 16 MB、最多 31 张图片。动画桌宠请导入桌宠 ZIP，本工具会保留其动画。
本地编辑与导出可离线；AI 生图需要联网，由所填服务商计费。密钥仅当前运行使用。预览为视觉示意。程序未做代码签名。
