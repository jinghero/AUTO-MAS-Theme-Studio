# MAS 创作工具箱

独立的 Windows 主题工坊与桌宠工具，包含图片导入、主题预览、OpenAI 兼容生图、主题 ZIP 导出、桌宠动画预览和独立桌宠包导出。

[下载 Windows 便携版](https://github.com/jinghero/AUTO-MAS-Theme-Studio/releases/latest) · [图文操作指南](guide.md)

- 主题采用标准 `theme.json` + 图片素材的 ZIP 格式，可导入 AUTO-MAS。
- 预览复用 MAS 的导航、主页组件与 Ant Design Vue 主题算法。
- 右侧预览铺满可用区域，宽高随窗口、最大化和全屏同步调整。
- 内置背景、封面、图标、静态桌宠、光标五类生图提示词。
- 一键生成整套 11 个菜单图标，逐项说明用途、编辑提示词、预览与勾选应用。
- 生成原图、提示词和原参考图自动存入本地素材库，跨主题、重启后复用提示词会自动带上当时的参考图。
- 桌宠支持动作切换、逐帧播放、图集检查和标准 `mascot.json` ZIP 导出。

![MAS 主题工坊：主题编辑与实时预览](docs/images/guide-01-theme.png)

## 快速上手

1. 下载并完整解压便携 ZIP，双击 `MAS主题工坊.exe`；无需安装 AUTO-MAS、Node.js 或 Python。
2. 填写主题信息，在「配色与背景」「图片素材」导入素材，也可打开附带的示例主题体验。
3. 需要 AI 时填写服务地址、模型名和 API Key，添加参考图，编辑提示词后生成。可先用看图模型生成候选提示词。
4. 预览后应用生成图片；菜单图标可一次生成 11 张，每项都有自己的用途与主体要求。
5. 在「本地素材库」复用图片或提示词；复用提示词会恢复原参考图。最后检查并导出 ZIP，在 AUTO-MAS 导入外观包。

各步的按钮位置、参考图恢复、整套图标、桌宠预览和备份方法见 [guide.md](guide.md)。

## 页面标题色

在「配色与背景」勾选「单独设置页面标题色」，可分别设置主题色和页面大标题色；点击「预览页面标题」查看效果。按钮、菜单、正文和卡片标题仍使用原来的配色。切换浅色/深色模式或配色灵感会保留独立标题色，「恢复 MAS 默认配色」会同时清除它。

取消勾选后恢复各页原有样式。旧主题默认不启用，打开并直接导出也不会自动加入标题色。主题包使用可选字段 `tokens.colorPageTitle`（`#rrggbb`），需搭配包含独立标题色支持的 MAS；较旧 MAS 会忽略该字段，其他主题效果照常。

## 运行

需要 Windows 和 Node.js 22.16 或更新版本。在此目录打开 PowerShell：

```powershell
npm ci
npm start
```

依赖在本项目内安装，不需要安装或克隆 AUTO-MAS。已包含构建好的 MAS 预览资源，可直接启动。

## 构建

```powershell
# 修改 preview-src 后重新生成 MAS 预览
npm run build:preview

# 打包 Windows 便携版
npm run build
```

输出位于 `dist/MAS创作工具箱` 和 `dist/MAS创作工具箱-便携版.zip`。

仅在维护上游快照时，`node setup.cjs` 从 AUTO-MAS 的 `upstream/dev` 更新主题校验模块，`node prepare-preview.cjs` 更新 MAS 布局与主页组件。它们默认使用相邻 `../AUTO-MAS`，也可通过 `AUTO_MAS_REPO` 指定目录。日常启动、构建和验证无需运行这两条命令。

## 目录

- `app/`：Electron 主进程、主题编辑器、AI 接口和完整运行资源。
- `app/mascot-tool/`：合并的桌宠工具源码。
- `app/compat/`：MAS 主题/桌宠校验代码及原始 TypeScript。
- `preview-src/`：MAS 预览源码、复用组件与来源参考。
- `app/mas-preview/`：已构建的预览运行资源，首次启动可直接使用。
- `verify*.cjs`：本地验证脚本。
- `guide.md`、`docs/images/`：图文操作指南及界面截图。
- `使用说明.txt`、示例 ZIP：工具用法和示例资源。

草稿在 `data/`，验证产物在 `qa/`，打包产物在 `dist/`；这些目录及 `node_modules/` 均已加入忽略规则。

本地素材库位于 `data/generated-images/`，每张原图配有用途、生成提示词、模型、时间、参考图对应关系及小尺寸预览。输入参考图保存在其中的 `references/`，按原始内容去重，一套图标共用的参考图只保存一份。工具所在目录不可写时，草稿与素材库一起保存在系统应用数据目录，界面会显示实际路径并提供打开文件夹按钮。升级到新文件夹或换电脑时，请备份并迁移整个 `data/` 文件夹；发布包不包含个人草稿、素材库或参考图。

## 验证

```powershell
npm test
```

验证默认使用仓库附带的示例主题与桌宠。设置 `THEME_FIXTURE` 后，主题往返检查也可使用其他兼容的主题 ZIP。AI 检查使用本地模拟服务，不消耗实际 API 额度。

打包后可运行 `npm run check:packaged`，验证便携版 EXE 的主题编辑、桌宠工具和 AI 接口流程。

## 持续集成

向 `main` 推送或提交以 `main` 为目标的 PR 时，GitHub Actions 会在 Windows 上安装锁定依赖、构建 MAS 预览、运行源码回归、打包并验证便携版 EXE。也可在 Actions 页面手动运行。

成功后，运行页面的 Artifacts 提供 `MAS-Theme-Studio-Windows-x64` 下载，保留 14 天；失败时截图与 JSON 报告保留 7 天。CI 不需要生图 API Key。

在 [Releases](https://github.com/jinghero/AUTO-MAS-Theme-Studio/releases/latest) 下载便携 ZIP，解压后双击 `MAS主题工坊.exe` 即可使用，无需 Node.js。发布页同时提供 `SHA256SUMS.txt` 校验文件。

维护者推送 `v` 开头的版本标签（如 `v1.0.0`）后，Release 工作流会检查标签与根目录、应用及锁文件的版本是否一致，复用完整 Windows CI，通过后上传便携 ZIP 和 SHA-256 校验文件。包含 `-` 的版本标签发布为预发布版本，其余发布为正式版。普通分支推送不会发布 Release。

## AI 生图

在「AI 生图」中填写 OpenAI Images API 兼容地址、模型名和 API Key。默认地址为 `https://api.openai.com/v1`，默认模型名为 `gpt-image-2`，可修改为服务商提供的名称。

「参考图」可添加最多 4 张 PNG、JPEG 或 WebP，单张不超过 8 MB、合计不超过 16 MB。可预览、单独移除，并在提示词里说明参考哪张图的人物、配色或风格。生成时通过标准 `multipart/form-data` 上传到 `/images/edits`，服务商和模型需支持该接口；不选参考图时使用 `/images/generations`。完整接口地址会按是否选择参考图自动切换。成功生成时，原参考图会随素材归档在本机，保留原始字节、文件名与顺序，不加入导出的主题包。

也可点击「根据参考图生成提示词」：在「参考图转提示词设置」填写支持图片输入的看图模型，默认复用生图地址和密钥；生图服务没有看图能力时，可勾选「使用独立的看图服务」填写另一组地址和密钥。看图使用兼容 `/chat/completions` 的多模态接口，结合当前用途、风格和参考图生成中文候选提示词。候选可编辑，点击「使用此提示词」后才替换当前提示词；失败、取消或切换主题不会覆盖原文。点击时会上传参考图与用途要求并由所选服务计费，密钥仅在本次运行的内存中使用。

图片生成支持 `data[0].b64_json` 或 `data[0].url` 返回格式，需使用 Images API；仅提供聊天接口的服务可用于看图转提示词，不能用于图片生成。不支持异步任务轮询接口。生图按所填服务商的规则计费。密钥仅本次运行使用，不写入草稿、主题包或日志。本地素材导入和导出可离线进行。

菜单图标可选择单张用途，也可勾选「批量生成整套菜单图标」：包含正式界面 10 个菜单及默认图标，共 11 张。每张分别描述用途与主体（如主页的房屋、计划管理的日历、设置的齿轮），共同使用风格、配色和原参考图，专属提示词可逐项修改。整套生成会顺序发起 11 个独立请求，分别计费；取消或失败后保留已完成项，可继续未完成项或单独重新生成。预览后勾选应用，图标自动缩小至 128 像素以内。开发者菜单及已移除的工具入口不出现在选择列表中，旧主题内的相关素材仍被保留。

所有成功生成的图片（含每个批量图标）自动保存原始字节到本地素材库，同时保留提示词、用途、风格、模型和参考图信息。新建主题或重启不会清空素材库。「选用图片」恢复原图预览，确认后应用；「复用提示词」恢复用途、提示词和当时的整组参考图，并替换当前选择，再次生成时直接上传这些原参考图。原记录没有参考图时恢复为 0 张。API Key 不归档，服务配置与密钥请自行确认。

v1.3 及更早的记录会标明「旧记录未保存参考图」，复用时提醒检查当前选择，无法自动找回当时没有保存的图片。参考图文件缺失或损坏时提示错误，不覆盖当前输入。原图归档失败时可重试保存，批量生成会暂停以保留当前原图。旧草稿中仍保留的最后结果也会补存；之前已被覆盖且未另存的图片无法追溯恢复。仍可用「保存图片」另存原图，主题 ZIP 只包含已应用的素材。

维护指南截图：`npm run docs:images`。脚本使用隔离的本地演示实例，不读取个人草稿、不调用付费模型。
